# 🛍️ Refily

A modern Flutter shopping application built to explore real-world app architecture, state management, local caching, and backend integration.

> ⚠️ This project is currently under active development.

---

## ✨ About

Refily is a personal learning project focused on building a production-style Flutter application using Clean Architecture and modern Flutter development practices.

The goal is to learn and apply concepts such as:

- Clean Architecture
- Riverpod State Management
- Local Database (Isar)
- Backend Integration (Supabase)
- Feature-based project structure
- Scalable and maintainable codebase

---

## 🚀 Current Features

- 📦 Product browsing
- 🏷️ Category-wise product listing
- 🎠 Auto-sliding promotional banner
- 🔀 Banner navigation to categories
- ❤️ Wishlist with local Isar caching
- ⚡ Fast local wishlist loading
- 💎 Shimmer loading effect
- 🧩 Freezed models with JSON serialization
- 🌐 Supabase integration
- 🏛️ Clean Architecture
- ⚙️ Riverpod dependency injection
